## 工作线与持久目录

复用 `goal` 作为持续业务目标，`task-plan` 保存归属和接续关系，保留每工单独立身份与 Run。Router 管目标、授权范围、依赖与进度；Executor 管技术拆解和实施，审查者独立核验。工作线不要求智能体进程永久运行。

- 开放任务的补充需求使用 `route attach`。新阶段使用 `route accept --goal ID`；同一精确 location 只有一个已完成前驱目录时默认续用。
- 已有开放任务时拒绝隐式新增写入者；确属独立并行工作时显式 `--workspace isolated`。多个候选目录要求显式 `--continue-from`。只读及授权远程操作可使用 `--workspace inspect`。
- `goal adopt --id GOAL --ticket TICKET` 仅补充此前为空的工作线归属，不能改已有目录、范围、派工或自动建立接续关系。
- `goal close` 要求没有开放任务；`goal reopen` 不复活已停止的工单。完成不删除目录。既有联合验收目标仍沿用原验收身份与冻结规则，新一轮独立联合验收应另建目标。

回收沿用创建者的工作区所有权，同时检查所有共用目录任务的派工、终端及工作线。历史依赖记录本身不永久阻止回收；开放任务、未归档工作线、备忘录或交接证据仍引用目录时保留。额外提交、脏文件、忽略文件及保留终端均禁止自动删除。

清理必须先提交实际只读调查证据，不能用 Git 干净替代服务引用核验：

```json
{"directory":"/exact/worktree","checkedAt":"2026-11-03T05:00:00.000Z","checks":["实际完成的服务挂载、配置路径和证据引用调查"],"references":[]}
```

通过 `cleanup references --ticket ID --fingerprint REFERENCE_FINGERPRINT --evidence /absolute/assessment.json --lease TOKEN` 记录。有效期一小时，并绑定当前目录清单及证据内容。它是人工/Executor 调查的记录机制，不是任意服务器依赖扫描器。`cleanup remove` 重新检查后非强制删除。结果不明先用原 fingerprint 对账；确认删除前失败且原清单完整不变时才允许 `cleanup reset` 解除锁定，再重新检查后重试。变化或部分删除仍保留待调查。

## 工程备忘录与交接

复用版本化 `knowledge`，不新增记忆数据库。Executor 的 `memo list|add|supersede` 受当前 assignment 能力及冻结执行范围约束；只允许写工程事实，不能覆盖用户裁决或其他组件/位置事实。写入要求来源、版本，重复重试幂等，冲突须显式处理。协议禁止写凭据值；未实现凭据内容的自动识别过滤。

默认事实范围为精确 location，可显式选择 component 或 goal。`report` 支持 `--next-step` 和 `--evidence`，持久保存交接。`read` 返回 `contextFile`，指向状态目录 `worklines/<scope-hash>/WORK.md`：它是唯一事实库的自动生成投影，不应手工维护第二份规则。无需修改业务仓库的 AGENTS.md，也不依赖某个智能体的私人聊天记忆。

## 后台通道

用户于本轮明确选择：先落地原生聊天交互，之后再增强终端的无干扰后台通道。

- OSA 使用 Orca 原生结构化聊天和 orchestration 消息来源标识，不向人工 PTY 输入框发送提醒。固定事件发送端仅作为来源身份，不是用户对话入口。
- 待办、消息、告警保存在 OSA 数据库；提示仅负责唤醒。新增/变化事项合并提醒，15 秒内合并；队列减少不再触发重复提示。发送不明时用同一请求 ID 对账。
- 看门狗检测逻辑保留，提醒改写入私有事件文件，OSA 导入成系统 notice。服务停机可积压，恢复后导入；已确认事件重放不重建通知，不生成用户请求或业务工单。损坏文件保留并通知一次，文件变化才重新通知。
- `bin/osa-router-chat.ts` 在调用 Orca 前持久保存创建意图，模糊结果可原样重试；不更改现有 Claude Code 模型配置。
- OSA 服务重启可续收。Orca 本身重启、聊天关闭或发送端被关闭，需要核验当前身份并重新绑定；当前不自动猜测新身份。未绑定时保留待办并暴露异常，不回退到 PTY 注入。

旧终端中的原生信箱及已发送历史提醒不会被清空。新入口完成后，旧窗口只保留查阅；向旧窗口继续发送新目标不会自动转给新聊天。
