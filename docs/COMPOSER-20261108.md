# 工作台输入栏实施

所有者要求实现 Orca 原生输入栏级别的输入框。本轮采用工作台自己的 HTML 输入栏，不修改 Orca 本体或 vendor。

公开插件只提供 Textarea 等控件，没有可直接嵌入的原生聊天 composer。实现可用的输入能力：多行、自适应高度、粘贴截图、拖拽和选择文件、附件预览与移除、上传状态和重试、草稿、快捷键及真实附件交付。模型、权限、技能仍通过既有角色和配置管理，不添加无效选择器。

- 项目当天请求与任务补充都支持文字和附件；附件可以单独发送，原始 text 保持为空，不伪造用户指令。
- 文件保存到当前 OSA 状态目录，消息只携带已完成附件的身份和元数据，Router／Executor 可读取原文件。
- 受原生消息大小限制，上传和下载使用小块传输；历史状态不嵌入 base64。
- 单文件上限 20 MiB，每条消息最多 10 个附件；界面明确提示限制。
- 草稿保存已上传附件引用；未完成上传的文件不能伪装成已保存。移除草稿附件不删除历史文件。
- 图片仅预览已识别 PNG/JPEG/GIF/WebP，其他文件按文件呈现，不执行附件内容。
- Enter 发送，Shift+Enter 换行，Cmd/Ctrl+Enter 发送；中文输入法确认不触发发送。
- 背景刷新保留输入焦点、光标、附件和未发送文字；失败不清空，重试沿用同一消息身份。

实现后验证：隔离单元与真实 Chromium 输入交互；原生插件加载；实际上传文件、历史回看，以及 Agent 通过图像工具读取验证图。最后统一加载正式服务，不向业务群发送测试附件。

当前：已实现并加载正式服务 `.osa/p4-live`。没有推送远端。
