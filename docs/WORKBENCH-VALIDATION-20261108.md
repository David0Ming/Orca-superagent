## 实现

- Orca 公开 `customEditors` 承载 `workbench.html`；侧栏“打开任务工作台”和原生新建文件菜单均有入口。没有 HTTP 服务、前端框架或新依赖，不修改 Orca 本体与 vendor。
- `.osaworkbench` 只是打开页面的标记文件，任务继续来自现有 OSA 服务。原任务、配置及旧侧栏页面仍可用。
- 日期／项目／工作树视图使用同一话题投影；项目内按日期，今天可直接输入。搜索覆盖任务、消息、项目及工作树，状态可筛选。
- 提出当天和后续活动日指向同一任务，轮询不制造每日进展。日期使用本机时区；无时间记录明确标注。
- 项目栏为来源上下文。Router 可以记录理由后路由到其他项目，原入口、原文与回复位置保留；已有任务补充仍由原执行者先判断。
- 未接单话题可继续评论，接单后保留选择与草稿；查询后接单、交回到另一任务均不抢走旧话题身份。
- 已记录的原话、判断、精确关联回复和报告按时间显示；完整原生聊天未被自动保存，界面明示这一范围。
