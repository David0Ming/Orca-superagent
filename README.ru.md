# Orca-superagent (OSA)

**Несколько компьютеров. Несколько агентов. Единое пространство для совместной работы.**

Передайте цель Router, а выполнение — агентам. Следите за ходом работы на одной панели, используйте Orca для удалённого доступа и управления другими компьютерами и принимайте ключевые решения.

## От Human to Human к Agent to Agent

| Взаимодействие | Как продвигается работа |
| --- | --- |
| **Human → Human** | Люди общаются, распределяют работу и передают её друг другу |
| **Human → Agent** | Человек описывает цель, агент выполняет задачу |
| **Agent → Human** | Агенты сообщают о ходе работы, задают вопросы и выносят ключевые решения на рассмотрение человека |
| **Agent → Agent** | Агенты делегируют задачи, возвращают результаты и передают вопросы, продвигая работу вместе |

**OSA переносит взаимодействие Agent to Agent в повседневную среду разработки.** Router уточняет цели и распределяет задачи. Executors планируют, исследуют, реализуют и отлаживают. Вы задаёте направление, агенты выполняют работу и передают её друг другу.

## Почему OSA

- **Одна точка входа, много задач.** Описывайте цели обычным языком, организуйте параллельную работу Claude Code, Codex и других агентов и получайте отчёты в общем входящем ящике.
- **Несколько компьютеров, одна рабочая среда.** Удалённое управление и поддержка нескольких компьютеров в Orca дают доступ к локальным и удалённым сеансам и рабочим пространствам.
- **Ход работы с первого взгляда.** Встроенная боковая панель распределяет задачи по разделам: Нужно ваше участие, Готовы к запуску, Ожидание внешних событий, В работе и История. Доступна группировка по проекту, рабочему пространству и агенту.
- **От общей картины к конкретному сеансу.** Раскройте задачу, чтобы прочитать переписку и записи, найдите окно выполнения или нажмите `@`, чтобы скопировать ссылку на задачу и продолжить разговор с Router.
- **Сопровождение длительных задач.** Для решений записываются конкретные вопросы, для ожидания — даты проверки, а назначения и отчёты сохраняют контекст для продолжения работы.

OSA объединяет разделение ролей из dsh-superagent и подход autoloop к событиям и таймерам со встроенной оркестрацией, визуальными рабочими пространствами и удалённым доступом Orca, связывая цель с местом выполнения работы.

## Как это работает

```text
Ваша цель → Router: уточнение и назначение → Executor: выполнение
                       ↑                             ↓
                Ключевые решения ← Вопросы, ход работы, результаты

Orca: окна выполнения · рабочие пространства · входящие сообщения · удалённые подключения
Панель OSA: просмотр задач, отслеживание работы, переход к нужному сеансу
```

## Быстрый старт

Подготовьте Orca и агента с выполненным входом в аккаунт, например Claude Code или Codex.

1. Поместите [навык Router](skills/osa-router/SKILL.md) в каталог навыков агента, например `~/.claude/skills/osa-router/SKILL.md`.
2. Поместите [правила Executors](skills/executor-rules.md) в `~/osa-team/executor-rules.md`.
3. Выполните команду из корня репозитория и подтвердите запрошенные Orca разрешения плагина:

```sh
orca plugin install ./plugin/osa-panel
```

Начните задачу в окне Orca:

```text
/osa-router Исправь ошибку входа в этом проекте и проверь результат локально
```

Продолжите существующую задачу:

```text
/osa-router resume <имя-задачи>
```
