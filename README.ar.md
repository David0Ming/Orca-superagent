# Orca-superagent (OSA)

**حواسيب متعددة. وكلاء متعددون. مساحة واحدة للتعاون.**

حدّد الهدف لـ Router ودع الوكلاء يتولّون التنفيذ. تابع التقدّم من لوحة واحدة، واستخدم Orca للوصول إلى الحواسيب الأخرى والتحكّم فيها عن بُعد، واتخذ القرارات المهمة في وقتها.

[中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · [العربية](README.ar.md)

## من Human to Human إلى Agent to Agent

| نمط التعاون | كيف يتقدّم العمل |
| --- | --- |
| **Human → Human** | يتواصل الأشخاص ويوزّعون العمل ويسلّمونه لبعضهم |
| **Human → Agent** | يصف الشخص الهدف وينفّذ الوكيل المهمة |
| **Agent → Human** | يقدّم الوكلاء التقارير ويطرحون الأسئلة ويعرضون القرارات المهمة على الأشخاص |
| **Agent → Agent** | يفوّض الوكلاء المهام ويتبادلون النتائج وينقلون الأسئلة لدفع العمل معًا |

**يُدخل OSA تعاون Agent to Agent إلى بيئة التطوير اليومية.** يوضّح Router الأهداف ويوزّع المهام، بينما يتولّى المنفّذون (Executors) التخطيط والاستكشاف والتنفيذ وتصحيح الأخطاء. أنت تحدّد الاتجاه، والوكلاء يتولّون التنفيذ وتسليم العمل فيما بينهم.

## لماذا OSA؟

- **مدخل واحد لمهام متعددة.** صِف أهدافك بلغة طبيعية، ونسّق العمل المتوازي بين Claude Code وCodex وغيرهما، واجمع التقارير في صندوق وارد موحّد.
- **حواسيب متعددة في بيئة عمل واحدة.** تتيح إمكانات التحكّم عن بُعد وإدارة عدة حواسيب في Orca الوصول إلى الجلسات ومساحات العمل المحلية والبعيدة.
- **التقدّم واضح من نظرة واحدة.** تنظّم اللوحة الجانبية المدمجة المهام ضمن: تحتاج تدخّلك، جاهزة للبدء، بانتظار أحداث خارجية، قيد التنفيذ، والسجل. ويمكن تجميعها حسب المشروع أو مساحة العمل أو الوكيل.
- **من الصورة العامة إلى الجلسة المعنية.** وسّع المهمة لقراءة المحادثات والسجلات، وانتقل إلى نافذة التنفيذ، أو اضغط `@` لنسخ مرجع المهمة ومتابعة الحوار مع Router.
- **متابعة المهام الطويلة.** تُسجَّل أسئلة محدّدة للقرارات، ومواعيد مراجعة لحالات الانتظار، وتُحفظ التكليفات والتقارير لدعم متابعة العمل.

يجمع OSA بين تقسيم الأدوار في dsh-superagent ونهج الأحداث والمؤقّتات في autoloop، وبين التنسيق المدمج ومساحات العمل المرئية والوصول عن بُعد في Orca، ليربط الهدف بمكان تنفيذ العمل.

## كيف يعمل؟

1. تصف الهدف لـ Router، فيوضّحه ويوزّع المهام.
2. ينفّذ Executor العمل ويعيد الأسئلة وتقارير التقدّم والنتائج.
3. تتخذ القرارات المهمة ويتابع الوكلاء العمل وفقها.

يوفّر Orca نوافذ التنفيذ ومساحات العمل وصناديق الوارد والاتصالات البعيدة. وتجمع لوحة OSA المهام وتعرض التقدّم وتوصلك إلى الجلسة المعنية.

## البدء السريع

جهّز Orca ووكيلًا مسجّل الدخول، مثل Claude Code أو Codex.

1. ضع [مهارة Router](skills/osa-router/SKILL.md) في مجلد مهارات الوكيل، مثل `~/.claude/skills/osa-router/SKILL.md`.
2. ضع [قواعد المنفّذين](skills/executor-rules.md) في `~/osa-team/executor-rules.md`.
3. شغّل الأمر التالي من المجلد الرئيسي للمستودع، ووافق على صلاحيات الإضافة التي يطلبها Orca:

```sh
orca plugin install ./plugin/osa-panel
```

ابدأ مهمة في نافذة Orca:

```text
/osa-router أصلح مشكلة تسجيل الدخول في هذا المشروع وتحقّق من النتيجة محليًا
```

لمتابعة مهمة موجودة:

```text
/osa-router resume <task-name>
```
